README - Dépôt LGLC-map
========================
ENGLISH VERSION BELOW

Ce dépôt contient les fichiers nécessaires à la création et à la visualisation de la carte interactive des événements du mouvement de Libération des Gais et Lesbiennes au Canada (LGLC).

LIEN DE VISUALISATION
=====================
La carte interactive est accessible directement à l'adresse suivante :
https://elisa-mayeur.github.io/LGLC-map/

DESCRIPTION DES FICHIERS
========================

Fichiers de données XML
-----------------------
• lglc-map.xml
  Fichier principal contenant les événements historiques du mouvement de Libération des Gais et Lesbiennes au Canada, encodés en XML-TEI.

• places-map.xml
  Fichier d'autorité des lieux contenant les définitions géographiques, les coordonnées et les informations d'adresse pour tous les lieux référencés dans lglc-map.xml.

Fichiers de transformation
--------------------------
• xml-to-geojson.xsl
  Feuille de style XSLT qui transforme les fichiers XML (lglc-map.xml et places-map.xml) en format GeoJSON. Cette transformation extrait les coordonnées géographiques et les métadonnées des événements pour créer des points sur la carte.

Fichiers de sortie
------------------
• lglc-map.geojson
  Fichier GeoJSON généré par la transformation XSLT. Contient les données géographiques des événements sous forme de points avec leurs propriétés (date, lieu, type de lieu, description de l'événement, identifiant de l'événement).

Fichiers web
------------
• index.html
  Page web principale qui affiche la carte interactive. Utilise la bibliothèque Leaflet pour la visualisation cartographique.

• lglc-map.css
  Feuille de style CSS personnalisée pour l'apparence de la carte et de l'interface web.

• leaflet.css et leaflet.js
  Bibliothèque JavaScript et feuille de style Leaflet pour la création de cartes interactives. Ces fichiers permettent l'affichage des marqueurs, la navigation et l'interactivité de la carte.

UTILISATION
===========

Pour visualiser la carte :

1. Accès direct en ligne (recommandé) :
   Accéder directement à : https://elisa-mayeur.github.io/LGLC-map/

2. Visualisation locale :
   - Télécharger l'ensemble des fichiers du dépôt
   - Ouvrir un terminal dans le dossier contenant les fichiers téléchargés
   - Lancer un serveur local avec la commande : `python3 -m http.server 8000`
   - Ouvrir un navigateur web et accéder à : `http://localhost:8000/index.html`

PROJET LGLC
===========
Ce dépôt fait partie du projet "Lesbian and Gay Liberation in Canada" (LGLC) codirigé par Constance Crompton et Michelle Schwartz, qui documente l'histoire de la libération lesbienne et gaie au Canada.

Pour plus d'informations sur le projet LGLC, consultez le site internet https://lglc.ca/.


ENGLISH VERSION

README - LGLC-map Repository
============================

This repository contains the files necessary for creating and visualizing the interactive map of events from the Lesbian and Gay Liberation movement in Canada (LGLC).

VISUALIZATION LINK
==================
The interactive map is directly accessible at the following address:
https://elisa-mayeur.github.io/LGLC-map/

FILE DESCRIPTIONS
=================

XML Data Files
--------------
• lglc-map.xml
  Main file containing historical events from the Lesbian and Gay Liberation in Canada, encoded in XML-TEI.

• places-map.xml
  Authority file for places containing geographical definitions, coordinates, and address information for all places referenced in lglc-map.xml.

Transformation Files
--------------------
• xml-to-geojson.xsl
  XSLT stylesheet that transforms XML files (lglc-map.xml and places-map.xml) into GeoJSON format. This transformation extracts geographical coordinates and event metadata to create points on the map.

Output Files
------------
• lglc-map.geojson
  GeoJSON file generated by the XSLT transformation. Contains geographical data of events as points with their properties (date, place, place type, event description, event identifier).

Web Files
---------
• index.html
  Main web page that displays the interactive map. Uses the Leaflet library for cartographic visualization.

• lglc-map.css
  Custom CSS stylesheet for the appearance of the map and web interface.

• leaflet.css and leaflet.js
  Leaflet JavaScript library and stylesheet for creating interactive maps. These files enable marker display, navigation, and map interactivity.

USAGE
=====

To visualize the map:

1. **Direct online access (recommended)**:
   Access directly at: https://elisa-mayeur.github.io/LGLC-map/

2. **Local visualization**:
   - Download all repository files
   - Open a terminal in the folder containing the files
   - Launch a local server with the command: `python3 -m http.server 8000`
   - Open a web browser and access: `http://localhost:8000/index.html`

LGLC PROJECT
============
This repository is part of the "Lesbian and Gay Liberation in Canada" (LGLC) project co-directed by Constance Crompton and Michelle Schwartz, which documents the history of lesbian and gay liberation in Canada.

For more information about the LGLC project, visit the website https://lglc.ca/.
